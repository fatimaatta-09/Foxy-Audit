{# ══════════════ TRUST MODEL ══════════════ #}

{% if anchor %}09{% else %}08{% endif %}Trust model

Every audit event is anchored to the one before it by a sequential SHA-256 hash chain, Hₙ = SHA256(dataₙ ‖ Hₙ₋₁). A modification that does not also rewrite every later chain value breaks the chain at the changed row. Records are content-blind: the ledger holds hashes and bounded metadata, never prompt or response text, so this document discloses no customer content.
