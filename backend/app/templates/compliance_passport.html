Trust Model

Every audit event in this report is anchored to the event before it via a sequential SHA-256 hash chain: Hn = SHA256(datan ‖ Hn-1) . Any modification to a historical record — by anyone, including the system operator — breaks the chain at the tampered row and every row after it. This is mathematically detectable by any party that holds a copy of the root hash.
